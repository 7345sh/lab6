## Средний уровень сложности

Добавлено решение 3 заданий средней сложности.

**app1.py** — задание 1, приложение типа «Hello World». Создано Flask-приложение с одним маршрутом "/", который возвращает строку «Привет, Flask!». Запуск через app.run(debug=True). Внешние файлы не используются, весь ответ формируется в коде.

**task3/** — задание 3, статическая страница с CSS. В папке находятся app.py, папка templates с файлом index.html и папка static с файлом style.css. HTML-страница вынесена в шаблон, стили — в отдельный CSS-файл. В шаблоне CSS подключается через url_for('static', filename='style.css'), страница отдаётся через render_template("index.html"). Flask автоматически ищет шаблоны в templates и статику в static.

**task5/** — задание 5, страница с Bootstrap. В папке находятся app.py и папка templates с файлом index.html. Bootstrap 5 подключён через CDN в шаблоне. Использованы готовые классы container, card, btn для оформления страницы без собственного CSS. Страница отдаётся через render_template("index.html").

## Повышенный уровень сложности

Добавлено решение 2 заданий повышенной сложности.

**adv_task1/** — задание 1, Flask с базой SQLite (CRUD). В папке находятся app.py и папка templates с файлами index.html и form.html. Реализованы создание, чтение, обновление и удаление заметок. Таблица notes создаётся при первом запуске через init_db. Подключение к базе через sqlite3, запросы параметризованы. Маршруты: главная со списком заметок, добавление, редактирование, удаление. Файл базы notes.db создаётся автоматически при первом запуске. Дополнительно: шаблоны оформлены через Bootstrap.

**adv_task4/** — задание 4, загрузка файла через форму. В папке находятся app.py и папка templates с файлом upload.html. Реализована форма с enctype="multipart/form-data" и полем file. Файл сохраняется в папку uploads, которая создаётся автоматически, имя очищается через secure_filename. Добавлен маршрут /uploads/<filename> для просмотра загруженных файлов через send_from_directory. Список загруженных файлов отображается на странице.

Для работы кода требуется установка библиотеки Flask. Установка осуществляется командой pip install -r requirements.txt.
